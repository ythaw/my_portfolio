# Yin Phyu Phyu Thaw — Portfolio

An interactive personal portfolio for **Yin Phyu Phyu Thaw**, a CS student at San José State University. Built as a playful, paper-and-stationery experience.

## Highlights

- **Intro chase** — Click “get to know me” to start!
- **About** — Book-style layout (overlay toggle on mobile)
- **Education** — Sierra College → SJSU transfer path
- **Projects** — AGENTIS, Let’s Cook, hand-tracking spells, Wordle clone, movie discovery, game manager, and more
- **Skills** — Floating bubble icons across languages, AI/ML, frameworks, and tools
- **Contact** — Folder-style “Leave a note.” card with email, LinkedIn, and GitHub
- Soft click sound, responsive layout, and reduced-motion support for the intro

## Tech

- React 19 + TypeScript
- Vite
- Custom layered sprite characters (idle, run, sit)
- CSS (no UI framework)
